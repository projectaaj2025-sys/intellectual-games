Подключение

Как подключить ключ

Ключ хранится только в вашем браузере и никуда не отправляется, кроме самого сервиса ИИ.

1

Выберите сервис

Оба варианта работают одинаково хорошо. Если ключа ещё нет — берите Google Gemini: он бесплатный и не требует привязки карты. OpenAI обычно даёт более точные вопросы по физике, но нужен платный аккаунт.

Google Gemini бесплатный тариф

Ключ: aistudio.google.com/apikey → «Create API key». Ключ начинается с AIza…. Карта не нужна, лимит — несколько десятков игр в сутки.

OpenAI нужен баланс

Ключ: platform.openai.com/api-keys → «Create new secret key». Ключ начинается с sk-…. Одна игра стоит примерно 1–3 цента.

2

Создайте ключ

aistudio.google.com/apikey platform.openai.com/api-keys

Скопируйте ключ сразу: OpenAI показывает его один раз. Если потеряли — удалите старый и создайте новый.

3

Вставьте ключ и нажмите «Проверить»

Сервис определится по префиксу ключа. Кнопка с галочкой рядом с полем проверит ключ, покажет доступные модели и выберет самую свежую из быстрых. Менять модель вручную не нужно.

Если автоподбор не сработал, впишите модель руками: gemini-2.5-flash или gpt-4o-mini. Список доступных моделей появится прямо в поле.
4

Сгенерируйте игру

Выберите предмет, класс, четверть и уровень юмора, затем нажмите «Сгенерировать игру». Обычно это 20–60 секунд. Готовый набор появится в предпросмотре, оттуда его можно открыть в игре или доработать в конструкторе.

5

Безопасность

  • Ключ хранится в localStorage этого браузера и не попадает в файлы игры или экспорт PPTX.
  • Запрос идёт напрямую из браузера в сервис ИИ. На чужом компьютере ключ может увидеть владелец сети — для публичных мероприятий создайте отдельный ключ с лимитом.
  • Кнопка «Забыть ключ» удаляет его с этого устройства.
